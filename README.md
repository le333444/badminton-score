# 羽毛球计分器

手机浏览器可用的羽毛球计分器：点左右两侧加分，每次自动播报比分，支持自定义队名、语速、多种计分规则。

---

## 一、最快用法：电脑起服务，手机打开（推荐）

1. **电脑上双击 `启动服务.cmd`**（需要电脑装了 [Node.js](https://nodejs.org/)，装一次即可）
2. 窗口里会显示两个地址：

   ```
   本机打开   :  http://localhost:8787/
   手机打开   :  http://192.168.x.x:8787/     ← 手机连同一个 WiFi
   ```

3. **手机浏览器打开「手机打开」那个地址**
4. 点 ⚙️ **设置 → 在线语音地址**，填 `http://192.168.x.x:8787`（就是上面那个地址，不带结尾斜杠）
   → 状态显示「**已连通**」后，每次加分都会用**真人语音**念出比分，**包括你自己填的队名**
5. 停止服务：关掉那个黑色窗口，或按 `Ctrl + C`

> 语音由 `server/server.js` 转发微软 Edge TTS 完成（免 key、免费）。
> 合成过的句子会缓存，**同一句第二次只需 1–5 毫秒**；常用比分会在后台自动预热。

### 为什么需要这一步？

手机自带浏览器（OPPO / vivo / 小米等）经常**没有中文语音引擎**，网页的「文字转语音」接口虽然存在，
但一开口就没声音。要念出**任意文字**（比如队名「张三」），只有两条路：

| 方案 | 是否要电脑伺候 | 能否念任意队名 | 速度 |
|---|---|---|---|
| A. 手机装中文语音引擎（Chrome + Google 语音服务 / 讯飞） | 不需要 | 能 | 最快（瞬时） |
| B. **本项目的本地语音服务**（本方案） | 需要电脑开着 | 能 | 首次 1–2 秒，缓存后毫秒级 |
| C. 预先录音内嵌（已废弃） | 不需要 | **不能** | 快 |

方案 A 最省事：装好引擎后，用 Chrome 打开本页即可直接用系统语音，连服务都不用起。

---

## 二、网页版的限制

本页托管在 GitHub Pages（纯静态，没有后端），所以：

- **不能用**手机自带语音引擎时（方案 A 不成立），网页自己无法合成语音
- 浏览器的 WebSocket 不允许带自定义请求头，所以网页**无法直连**微软的免 key 接口
  → 必须有一个转发服务（就是 `server/server.js`）

因此：**手机直连 GitHub Pages + 无中文引擎 = 只能看比分，没有语音**。想听语音请用上面的方案 A 或 B。

## 三、文件说明

```
index.html          计分器页面（单文件，含全部逻辑）
启动服务.cmd        Windows 双击启动（调用 server/server.js）
server/
  server.js         本地服务：托管页面 + /tts 语音接口 + 音频缓存
  edge-tts.js       Edge TTS 客户端（零依赖，只用 Node 内置 tls/crypto）
```

### 接口

| 接口 | 说明 |
|---|---|
| `GET /tts?text=十一比五&rate=1` | 返回 MP3 音频 |
| `POST /tts` `{"items":[{"text":"张三一比零"}]}` | 批量，返回 base64，供页面缓存 |
| `GET /health` | 健康检查 |

### 常见问题

- **端口被占用**：`set PORT=8899 && node server\server.js`
- **手机打不开**：确认在同一 WiFi；Windows 防火墙弹窗要点「允许」
- **语音报 403**：微软的接口版本号会过期，改 `server/edge-tts.js` 里的 `CHROME_VER` 为更新的 Edge 版本号
- **想要别的音色**：改 `server/edge-tts.js` 的 `DEFAULT_VOICE`，可选 `zh-CN-XiaoxiaoNeural`（女，默认）、
  `zh-CN-YunxiNeural`（男）、`zh-CN-XiaoyiNeural` 等

## 四、页面功能

- 左半屏点击 = 左边 +1 分，右半屏 = 右边 +1 分；每次自动播报
- 顶栏：`↩︎ 撤销`、`🔊 语音`开关、`⚙️ 设置`
- 设置项：语音开关、**播报方式**（自动 / 系统语音 / 在线语音 / 关闭）、**在线语音地址**、
  语速、计分规则（羽毛球 21 / 乒乓 11 / 15 分）、**队名**
- 21 分制含「领先 2 分胜、30 分封顶」；每局结束可「下一局」，局分自动累加，上局胜方先发球
- 比分与设置存在浏览器本地，刷新不丢；屏幕常亮；禁用双击缩放

键盘快捷键（电脑上调试用）：`A`/`←` 左方加分，`B`/`→` 右方加分，`Z` 撤销，`M` 静音开关。
